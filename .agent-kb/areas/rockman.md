# Rockman

## Map
- `src/rockman.c` — the game. `make rockman-host`, `make rockman-test`.
- `src/rockman_data.h` — generated by `tools/extract_rockman.py`. Do not hand-edit.
- `scratch/Rockman.asm` — the rules. Where a doc disagrees, the asm wins.
- `docs/ROCKMAN_PLAN.md` — the build brief. Some names in it are not in this asm (below).

## Facts
- [verified 2026-11-01 scratch/Rockman.asm DrawMapByte] A set map bit is `TILE_ROCK`, a clear bit is `TILE_DIRT`. Brick is the full-screen fill, not a map bit.
- [verified 2026-11-01 scratch/Rockman.asm ScanRocks] There is no `RotAt`. Scan is rows 1-12, cols 4-17, from the bottom-right, walking left then up. Dirt holds a resting rock. Empty, player or monster below starts a fall. Any other solid tile tries both sides; if both are free the rock is copied to both.
- [verified 2026-11-01 scratch/Rockman.asm PlaceRoomDiamonds] Every uncleared room gets 5 fixed diamonds plus 3 random ones. Rooms 15-20 are not a special case.
- [verified 2026-11-01 scratch/Rockman.asm ScoreAdd100] +100 a diamond (hi-score updates by falling into `UpdateHiScore`). +10 when a rock crushes a monster. +10000 when all 20 rooms are clear. The plan's 300 / 25×time / 1000 / 5000 adders are not in this asm.
- [verified 2026-11-01 scratch/Rockman.asm TryLeaveRoom] The top exit uses the same "room must be clear" test as the other three. A 0 in the exit table means no exit.
- [verified 2026-11-01 scratch/Rockman.asm MoveMonsters] Spawns are tile `0x21` only. They step on empty, on player tiles `0x1B`-`0x1F` (not `0x20`), and on dirt only when the random byte is under 5.
- [ran 2026-11-01 make rockman-test] Self-test passed, timer death on pass 6730. Title, room 1 and `--auto 24` dumps passed `check_pgm.py` and `check_rockman.py`.
- [verified 2026-11-01 src/menu.c] ROCKMAN is exit 5. WIFI moved from 5 to 6. KINDLE stays 0.

## Built
- Playable port. Entry: `src/rockman.c`. Device runner: `./run-rockman-on-kindle.sh`.
- Pictures from `make rockman-test`: `/tmp/rockman-title.pgm`, `/tmp/rockman-room.pgm`, `/tmp/rockman-play.pgm`.

## Decisions
- No audio. The tune stays in the header; the self-test only checks the table loaded.
- Exit 0 stays in the room. The asm would store room 0 and stick on the title picture.
- A diamond on the cell the player appears in is collected (+100, and it counts). Room 5's top door sits on one; painting over it made that entrance unwinnable.
- Monster frame memory is cleared at each room start, so the first move finds the type-A spawns. Leftover RAM freezes them about half the time.
- The win picture waits for a tap, then starts room 1 faster, same lives, same score. The asm flashed colours instead.
- The timer mark is an inverted digit. Diamond colour sparkle is not drawn.

## Dead ends
- Do not add `RotAt`, auto-firing traps, or the plan's extra score adders. They are not in `scratch/Rockman.asm`.

## Do not redo
- At speed 0 the timer kills on pass 6730 (256 for the first step, then 6 per step, 9 marks of 120). The self-test asserts that number.

## Open
- Not built or played on a Kindle yet. `make rockman-kindle` needs the `kfb-build` docker image.
